# marios-andr.github.io

A collection of web projects I made, including physics simulations, mathematics visualizations, and other tools, built with vanilla HTML, CSS, and JavaScript.

Website: [marios-andr.github.io](https://marios-andr.github.io)

---

## Projects

### Physics Simulations
- **Pendulum** — Interactive pendulum simulation with configurable length, angle, gravity, and mass. Displays force vectors and period analysis graphs.
- **Collisions** — Colliding blocks simulation.

### Mathematics
- **Graphing API** — Function graphing calculator.
- **Mandelbrot Set** — Interactive Mandelbrot set explorer.
- **Irrationality Visualization** — Visual representation of irrational numbers.

### Other
- **LaTeX Parser** — Renders LaTeX expressions in the browser.
